# Переключатель ОС без перепрошивки (план)

Статус: не делаем, описание схемы на будущее. Пункт в `TODO.md`.

## Зачем

Сейчас ОС выбирается при сборке: `-DOS_MAC` / `-DOS_LINUX` задают в блоке
«Target OS» (`config/corne.keymap`), какие клавиши шлют Cmd и Ctrl и какие
сочетания отправляют системные клавиши. Центральная часть прошивается под
одну ОС.

Со схемой с донглом этого хватает: донгл обычно один на компьютер. Без донгла
левая половина подключается к нескольким компьютерам через BT-профили
(BT 0–4 в Utils). Если среди них есть и Mac, и Linux, при смене компьютера
пришлось бы перепрошивать. Переключатель даёт одну прошивку на обе ОС.

## Схема

### Слои

| Слой | Что в нём | Как включается |
|---|---|---|
| Base | раскладка под Linux (как сейчас `-linux`) | всегда |
| Mac | только клавиши, которые на Mac другие, остальное `&trans` | переключатель |
| Nav, Num, Utils | как сейчас, под Linux | удержание thumb |
| Nav-Mac, Utils-Mac | Mac-варианты системных клавиш, остальное `&trans` | условный слой |

Что лежит в слое Mac (позиции, где отличаются Linux и Mac):

- модификаторы `SC` / `OT`: outer left (`SC_L`), A и `;` (`OT`), F и J (`SC`),
  левый thumb (`SC_L`); удержание Enter thumb (Hyper) от ОС не зависит и в слой Mac не входит;
- `'` с двойным тапом `SC(RET)`;
- в Num: `OT(F11)` / `OT(F12)` и hold-tap'ы цифр с `SC` / `OT`.

Nav-Mac и Utils-Mac: блокировка, скриншоты, Mission Control, рабочие столы,
слово / строка / документ, отмена / копирование / вставка.

Условные слои ZMK (`conditional_layers`, уже есть пустой узел в keymap):

```dts
conditional_layers {
    compatible = "zmk,conditional-layers";
    nav_mac   { if-layers = <NAV MAC>;   then-layer = <NAV_MAC>; };
    utils_mac { if-layers = <UTILS MAC>; then-layer = <UTILS_MAC>; };
};
```

Порядок слоёв: Mac выше Base, Nav-Mac выше Nav, Utils-Mac выше Utils (слой с
бо́льшим номером перекрывает меньший).

### Переключатель

Два варианта, можно оба:

1. Клавиша в Utils: `&tog MAC`.
2. Вместе с BT-профилем, макросами на месте BT 0–4 в Utils:
   «BT 0 / Mac» = `&bt BT_SEL 0` + включить Mac,
   «BT 1 / Linux» = `&bt BT_SEL 1` + выключить Mac.
   Профиль и ОС выбираются одной клавишей.

### Главная проблема: состояние не сохраняется

Стандартный ZMK не сохраняет включённые слои: после перезагрузки, в том числе
после пробуждения из глубокого сна (`CONFIG_ZMK_SLEEP`), включён только Base.
Выбранный BT-профиль при этом сохраняется во flash. После пробуждения
клавиатура подключится к Mac, но будет слать Linux-сочетания.

Решения:

- Сделать Mac раскладкой по умолчанию (Base под Mac, слой Linux поверх).
  Тогда после пробуждения всё верно для основного компьютера, для Linux надо
  нажать переключатель.
- Модуль ZMK, который сохраняет слой или «default layer» во flash (есть в
  сообществе, не проверены). Добавляется в `config/west.yml`.
- Своя небольшая behavior в модуле: при выборе BT-профиля включать слой ОС,
  заданный для профиля в keymap. Профиль восстанавливается при загрузке, а
  слой выводится из него. Самый надёжный вариант, но это код на C.

## Что поменяется в репо

- `config/corne.keymap`: вместо `#if defined(OS_MAC)` — оба набора имён
  (`MAC_SHOT_AREA`, `LINUX_SHOT_AREA`…), слои Mac / Nav-Mac / Utils-Mac.
- `build.yaml` / `scripts/firmware.py`: центральная часть собирается один раз,
  без `-mac` / `-linux` в имени файла; `flash.sh` и `flash-all.sh` без `--os`.
- Тесты: каждый кейс так же гоняется для двух ОС, для Mac перед сценарием
  нажимается переключатель (одна сборка вместо двух на кейс).
- Картинка: слой Mac, Nav-Mac и Utils-Mac рисуются отдельно, только с
  отличающимися клавишами.
- ZMK Studio покажет 3 новых слоя; запасные `extra1` / `extra2` остаются.

## Открытые вопросы

- Какая ОС по умолчанию после пробуждения.
- Привязка к BT-профилям: фиксированная (0 — Mac, 1 — Linux) или
  настраиваемая.
- Нужна ли индикация текущей ОС (на nice!nano без дисплея — только через
  Studio или по поведению клавиш).
